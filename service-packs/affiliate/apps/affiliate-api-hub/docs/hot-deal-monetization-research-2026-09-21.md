**지금 수집한 핫딜에 연결하는 방법**

1. 네이버 오늘끝딜에서 앞서 수집한 85개 상품 ID를 쇼핑 커넥트 대상 상품·수수료와 매칭한다. **수집 85개, 제휴 가능 여부 85개 미확인**이다. 확인된 제휴 가능 건수가 아직 0이라는 뜻이지, 실제 가능한 상품이 0이라는 뜻은 아니다. 품절·종료도 발행 전에 다시 확인한다.
2. 11번가 식품·생필품은 애드픽 후보, 일반 가전·디지털은 제외 규칙부터 확인한다. 다른 판매처의 제휴 상품을 찾더라도 모델·옵션·배송·쿠폰 조건이 같을 때만 비교한다.
3. SSG·오늘의집·LG·알리는 해당 몰의 캠페인과 채널 조건을 적용한다. 같은 제품이 여러 몰에 있어도 최저가 출처를 바꿔 쓰지 않는다.
4. 마리트는 이미 검증한 직접 제휴 링크 생성을 우선 활용하고, 실제 상품 요율을 다른 경유 프로그램과 비교한다. 직전 9/21 로컬 기록에서 정산 필수정보가 미완료이므로 링크 생성 성공과 입금 가능 상태를 구분한다.
5. 항공사 공식 홈페이지 전용 특가는 **항공사 구매 링크를 유지**한다. OTA에서 같은 날짜·편명·수하물·취소 조건·최종가가 확인될 때 제휴 대안을 추가한다. 공홈 특가를 OTA 링크로 바꿔도 같은 가격이 보장되는 것은 아니다.
6. 항공편 글의 목적지에 맞는 숙소·공항 이동·eSIM·투어는 별도 상품으로 연결할 수 있다. 항공사 공홈 직접 제휴는 이번 조사에서 확인하지 못했으며, 관련 상품 수수료와 항공권 수수료를 혼동하지 않는다.

직접 제휴가 언제나 네트워크보다 높다는 가정도 하지 않는다. **동일 상품의 최종 구매가, 실제 수수료 기준 금액, 취소 제외 후 확정 수익, 귀속 기간, 앱 조건**으로 비교한다. 글에는 이용하는 프로그램에서 정한 제휴 표시를 넣는다. [네이버 링크 발급·표시 안내](https://help.naver.com/service/30027/contents/24104?osType=COMMONOS)

재조회:

```powershell
# apps/affiliate-api-hub 디렉터리에서 실행; 최신 관측을 별도 파일에 저장
node tools/research/adpick-affiliate-catalog.mjs --out .runtime/adpick-public-malls-latest.json
```

스크립트는 공개 목록 읽기만 수행한다. 저장 항목은 몰 ID·이름·도메인·요약 요율·확정 시기·조건 해시 등이며 쿠키·토큰·개인 tracking link를 저장하지 않는다. 반복 실행에 브라우저가 필요하지 않다는 검증 범위도 이 읽기 작업에 한정한다.

링크프라이스의 공식 안내에는 회원가입·참여형 CPA도 있지만, 현재 핫딜 글에는 구매형 CPS부터 적용하는 것이 맞다. 실제 CPA는 해당 광고주의 유효 실적 정의·건당 단가·채널 승인을 확인한 뒤 별도 캠페인으로 운영한다. [공식 API 안내](https://www.linkprice.com/affiliate/views/affiliate_marketing/plus_service_api.html)

마리트는 여행 완료 후 지급하며 공식 안내에 월 10만원 초과·정산 확인과 미달 시 이월 조건이 있다. Viator는 이용 완료 기준으로 은행 송금 월별 최소 USD 50 또는 PayPal 주별 무최소액을 안내한다. 새 프로그램은 가입·추적 링크 발급만으로 지급 준비가 끝났다고 보지 않는다. [마리트 정산 안내](https://partner.myrealtrip.com/welcome/marketing_partner), [Viator 지급 안내](https://partnerresources.viator.com/)
