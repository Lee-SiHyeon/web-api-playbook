# 네이버 로그인·API 통합본

2026-09-24의 로그인 작업 폴더와 실제 발행에 사용한 최신 퍼블리셔를 함께 반입했습니다. 기존 통계 저장소의 이력과 55개 관측 계약은 유지합니다.

## 포함 범위

- 독립 HTTP 로그인, 관측된 로그인 토큰 발급 경로, 계정 보호 상태 처리.
- Windows DPAPI 계정 정보·쿠키 저장과 재사용, 관측된 Set-Cookie 회전 반영.
- 보호된 관리 화면 확인, 통계 55개, 편집기·초안·게시글 읽기.
- 글 생성·수정·태그 수정, 이미지·동영상 업로드와 업로드 결과 대사.
- 원문 문서·표·캡션 변환, API 전처리, 저널, 공개/소유자 리드백.
- 동적 글 품질 기준과 Jev 리뷰, 재발행 작업 흐름.

현재 구현은 `apps/naver-blog-api/`, 공유 검증 코드는 `packages/contracts/`에 있습니다. 루트의 기존 `scripts/`, `references/`, `discovery/`는 과거 통계 도구와 관측 기록입니다. 두 코드의 시점과 검증 범위를 구분하세요. [이전 README](history-before-login-20260924.md)의 로그인 미구현 설명은 과거 상태입니다.

## 설치와 실행

단계별 사용법은 [루트 README](../README.md), 새 글·기존 글의 실행 순서는 [발행 사용법](publishing-usage.md)을 따릅니다. Node.js 24 이상, 저장된 인증 재사용은 해당 Windows 사용자 계정이 필요합니다. 최초 입력 도우미는 PowerShell 7에서 실행합니다.

```powershell
npm ci --ignore-scripts
npm run login:auto
npm run session:health
npm run publisher:api -- --command=session-status --blog-id=aicandoanything
```

발행 런처는 작업 폴더를 앱으로 바꾸므로 입력·출력·저널 경로는 절대경로로 전달합니다. README의 예제는 이 조건을 반영합니다.

새 PC에서는 보호 저장소를 그 PC의 정상 로그인·자격증명 입력 흐름으로 초기화해야 합니다. Git clone은 로그인 상태를 복제하지 않습니다. 비밀번호·쿠키·토큰값, DPAPI 파일, 브라우저 프로필은 이 저장소에 넣지 않습니다. 저장·갱신 기능 자체는 포함돼 있습니다.

선택적인 이미지 해석 공급자는 별도로 설치·로그인된 Codex CLI를 사용합니다. 계정 보호나 추가 인증 상황이 모두 자동 복구된다고 보장하지 않습니다. 새 글에 필요한 SDK 토큰 제공 단계와 네이티브 미리보기는 별도 단계로 유지되며, 모든 발행 과정이 브라우저 없이 된다는 의미는 아닙니다.

실제 글 쓰기는 현재 승인한 대상·문서와 각 게이트를 충족해야 합니다. 응답이 모호하면 동일 저널과 관리 원문을 대사한 뒤 다음 동작을 결정합니다. 코드 반입을 위해 이번 작업에서 네이버 글을 새로 쓰거나 수정하지 않았습니다.

## 추가 도구 경계

제휴상품 전체 수집 흐름 `workflows/affiliate-content-e2e`는 기존 모노레포의 `affiliate-api-hub`가 필요한 선택 기능입니다. 네이버 로그인·통계·편집·업로드·발행 클라이언트에는 필요하지 않습니다. 모델 비교용 `workflows/model-compare`는 별도 모델 CLI와 FFmpeg를 사용하며, 경로 환경변수는 해당 문서에 따릅니다.

이번 Git 반입에서는 단위 테스트나 라이브 로그인/발행 시험을 새로 실행하지 않았습니다. 포함된 테스트와 과거 증거는 각각 작성 당시 범위이며, 현재 자격증명 유효성이나 전체 API의 현재 성공을 보장하지 않습니다. `IMPORT-2026-09-24.json`은 원본 파일 반입 해시와 작업 폴더 출처를 기록합니다.
