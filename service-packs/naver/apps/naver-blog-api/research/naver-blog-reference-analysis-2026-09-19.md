## 상위 게시물의 공통 구조

### 1. 상품 설명보다 먼저 독자의 장면을 연다

상위 글은 곧바로 사양표부터 시작하지 않는다.

예시 구조:

`아이들과 외출 → 사진·지도 사용 → 배터리가 간당간당 → 기존 대용량은 무거움 → 이번 제품 선택`

독자는 상품명이 아니라 자신의 상황을 먼저 발견한다.

### 2. 제목에 검색어 외에 한 가지 증거와 한 가지 긴장을 넣는다

강한 제목의 기본식:

`핵심 검색어 + 사용 상황/대상 + 경험 증거 + 장점 또는 단점`

실제 관측된 형태:

- `내돈내산 후기, 귀여운데 발열은 아쉬워요`
- `기내반입 가능한 미니 초고속 대용량 보조배터리`
- `5종 비교｜용량·충전속도·무게·포트까지 한눈에`
- `무거운 건 딱 질색! 1만원대 가성비 ... 찐사용기`

`추천`, `후기`만 붙이는 것보다 독자가 판단할 정보를 제목 안에 넣는다.

### 3. 신뢰는 장점보다 구체적인 단점에서 만들어진다

상위 1위 게시물은 발열과 거치대 안정성 문제를 별도 구획으로 길게 다뤘다.
그 뒤에도 왜 계속 가지고 다니는지를 설명했다.

추천 글의 설득력은 칭찬의 강도가 아니라 다음 조합에서 생긴다.

`사용 장면 + 숫자 + 불편했던 점 + 그래도 선택할 조건`

### 4. 한 덩어리 본문이 아니라 화면 리듬을 만든다

많이 관측된 SmartEditor 구성 순서:

`상황 텍스트 → 이미지 → 짧은 인용구형 소제목 → 이미지 → 실사용 설명 → 이미지 → 단점 소제목 → 결론`

자주 사용된 구성요소:

- 일반 텍스트 컴포넌트
- 단독 이미지와 이미지 스트립
- 인용구형 소제목
- 구분선
- 표 또는 요약 카드
- 쇼핑커넥트·OG 링크
- 짧은 영상

문단이 짧은 이유도 모바일 스크롤 리듬 때문이다. 긴 설명을 한 문단에 몰아넣지 않는다.

### 5. 독자의 결정을 끝내준 뒤 링크를 준다

좋은 CTA 직전에는 보통 다음 중 하나가 있다.

- 이런 분에게 추천
- 이런 분은 다른 제품이 나음
- 장점/단점 한 줄 요약
- 구매 전에 확인할 규격
- 비교표의 최종 승자

링크가 글의 목적처럼 보이면 광고가 되고, 결정 지원 뒤에 나오면 서비스가 된다.

## 레퍼런스에서 뽑은 5가지 포맷

### A. 단일 제품 실사용 후기

1. 독자의 불편한 상황
2. 왜 이 제품을 고르게 됐는지
3. 실물 첫인상과 구성품
4. 크기·무게 비교 사진
5. 핵심 기능 실제 사용
6. 충전 시간·발열·잔량 등 측정
7. 예상 밖 장점
8. 명확한 단점
9. 추천 대상 / 비추천 대상
10. 가격·배송·호환성 확인
11. 제휴 링크
12. 한 줄 결론

직접 사용하지 않았다면 이 포맷을 사용하면 안 된다.

### B. 비교형 구매 가이드

1. 어떤 사람이 무엇 때문에 검색하는지
2. 선택 기준 4~6개
3. 후보군 표
4. 후보별 강점과 약점
5. 상황별 우승 제품
6. 피해야 할 조건
7. 최종 선택 트리
8. 상품별 링크

제품을 보유하지 않아도 자료 출처와 확인일을 표시하면 정직하게 작성할 수 있다.

### C. 문제 해결형 정보글

예: `기내반입 보조배터리 규정 + 용량별 추천`

1. 실제 문제가 생기는 장면
2. 규정이나 원리 요약
3. 독자가 직접 계산·확인하는 법
4. 흔한 실수
5. 조건에 맞는 상품군
6. 체크리스트
7. 관련 상품 링크

검색 유입과 상품 전환을 동시에 노릴 수 있는 핵심 포맷이다.

### D. 리스트형 꿀템 글

1. 리스트 선정 기준
2. 3~7개 제품
3. 제품당 `한 줄 용도 → 장점 → 아쉬움 → 추천 대상`
4. 직접 산 것과 자료 조사 제품을 명확히 구분
5. 전체 순위보다 상황별 추천으로 마무리

### E. 계절·행사형 큐레이션

예: 신혼여행, 추석 귀성, 겨울 차량, 결혼식 비상키트.

`일정/상황 → 빠뜨리면 곤란한 물건 → 선택 기준 → 실제 준비 목록 → 상품 링크`

사용자의 실제 일정과 준비 과정을 담을 수 있어 차별화가 가장 쉽다.
