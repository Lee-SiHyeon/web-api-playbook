# 단일 제품 실사용 후기 템플릿

## 제목 공식

`[핵심 키워드] + [사용 상황] + [직접 경험] + [장점/단점]`

예:

`도킹형 보조배터리 내돈내산 후기｜작아서 편한데 발열은 어땠을까`

## 본문

### 제휴 고지

첫 화면 안에 명확하게 표시한다.

### 1. 왜 필요했나

실제 사용자의 하루와 문제가 생긴 장면을 2~4개 짧은 문단으로 작성한다.

### 2. 선택 이유

- 비교했던 다른 선택지
- 최종 선택 기준
- 구매 가격과 구매 시점

### 3. 구성품·크기·무게

실물 사진, 손이나 일상 물건과의 크기 비교, 실제 무게.

### 4. 핵심 기능 1

기능 설명보다 사용 장면과 결과를 먼저 쓴다.

### 5. 핵심 기능 2

측정 가능한 숫자를 포함한다.

### 6. 좋았던 점

장점마다 사진 또는 구체적 사례를 붙인다.

### 7. 아쉬웠던 점

구매를 말려야 할 조건까지 명확히 적는다.

### 8. 이런 분에게 추천

3~5개 체크리스트.

### 9. 이런 분은 다른 제품

2~3개 조건.

### 10. 최종 결론

누구에게 어떤 용도로 가치가 있는지 한 문단으로 끝낸다.

### 11. 상품 확인

가격·배송·옵션 변동 안내 후 제휴 링크.
