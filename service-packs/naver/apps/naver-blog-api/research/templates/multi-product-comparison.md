# 다제품 비교형 제휴 글 템플릿

## 제목 공식

`[제품군] N종 비교｜[서로 다른 선택축] 중 [선택 제품]이 매력적인 이유`

예:

`도킹형 보조배터리 5종 비교｜5천원대·20W·1만mAh 중 스피디가 맞는 사람`

## 0. 제휴 고지와 확인 시각

- 제휴 고지는 첫 화면에 표시한다.
- 가격·재고·옵션 확인 시각을 표시한다.
- 직접 써보지 않았다면 `가격·사양·공개 후기 분석`임을 밝힌다.

## 1. 독자가 실제로 고르는 상황

다음 중 어느 쪽인지 먼저 나눈다.

- 작은 가방·비상 충전
- 출퇴근 중 빠른 충전
- 여행 중 하루 종일 사용
- 가족·커플용 묶음 구매
- 두꺼운 케이스·단자 호환 우선

## 2. 비교 기준

| 기준 | 독자 질문 | 증거 종류 |
|---|---|---|
| 현재 가격 | 얼마를 더 내는가 | 판매 화면과 확인 시각 |
| 용량 | 비상용인가, 하루용인가 | 공식 사양 |
| 출력 | 20W 이상이 필요한가 | 공식 사양·측정 |
| 휴대성 | 가방과 사용 중 부담 | 무게·크기·사진 |
| 단자 | C타입·8핀·맥세이프 | 공식 옵션 |
| 케이스 호환 | 장착한 채 꽂히는가 | 실측·후기 반복 신호 |
| 발열·내구 | 반복 불만이 있는가 | 여러 후기·커뮤니티 |
| AS·안전 | 인증과 대응은 어떤가 | 공식 출처 |

## 3. 후보 4~7개 한눈에 비교

후보는 같은 제품군 안에서도 역할이 달라야 한다.

- 절대 최저가
- 선택 제품
- 고속충전형
- 대용량형
- 묶음 가성비형
- 프리미엄·편의형

## 4. 각 비교축의 승자

제품 하나가 모든 축에서 이긴다고 쓰지 않는다.

### 가격 승자

왜 싸고, 무엇이 빠졌는지.

### 충전 속도 승자

추가 비용과 용량을 함께 쓴다.

### 하루 사용 승자

용량 이점과 무게·부피를 함께 쓴다.

### 단가 승자

묶음 수량·옵션·교환 조건을 확인한다.

## 5. 선택 제품이 매력적인 정확한 이유

`무조건 최고`가 아니라 다음 문장을 완성한다.

> 이 제품은 `[독자 상황]`에서 `[가격/기능 균형]` 때문에 매력적이다. 다만 `[다른 기준]`이 중요하면 `[대안]`이 더 낫다.

## 6. 선택 제품이 지는 조건

최소 2개를 공개한다.

## 7. 추천 대상 / 비추천 대상

각각 3개 이상.

## 8. 커뮤니티 반복 질문 검증

- 케이스 호환
- 단자 흔들림
- 발열
- 실제 충전량
- 충전 중 조작성
- 장기 내구

커뮤니티 의견은 빈도와 상황을 요약하고, 내 경험처럼 서술하지 않는다.

## 9. 최종 선택 트리

```text
가격 최우선 → 최저가 후보
속도 최우선 → 20W 이상 후보
하루 사용 → 10,000mAh 후보
작은 가방·비상용 → 선택 제품
2개가 필요 → 묶음 후보
```

## 10. 링크

선택을 끝낸 뒤 각 제품 링크를 제공한다.
