# 네이버 블로그 API 탐색

대상: https://blog.naver.com/4053103

기존 Chrome의 입력된 계정으로 로그인하여 관리 화면 진입을 확인했다. POST https://nid.naver.com/nidlogin.login 요청을 관측했으며 로그인 전체의 독립 HTTP 재현은 미완료다. 로그인 원문·쿠키·비밀번호는 저장하지 않았다.

기본 정보, 스킨, 메뉴 관리, 통계의 4개 관리 경로를 확인했다. 많은 관리 기능은 iframe 문서 이동을 사용한다. 독립 통계 클라이언트 stat-client.mjs는 stdin의 {"url":"관측된 URL"}과 런타임 NAVER_COOKIE로 GET https://blog.stat.naver.com/api/blog/daily/cv 를 실행한다. query 필드는 timeDimension, startDate, exclude, _ 이며 값은 현재 관측 요청에 따른다. HTTP 200, application statusCode 200, 7개 통계 항목 응답을 별도 Node 프로세스에서 확인했다. stat-replay.json에 타입·길이·해시 증거가 있다.

현재 CDP 이벤트 수집기는 네이버 블로그·로그인·통계 도메인을 감시하며 cdp-events.jsonl에 비밀값 없이 기록한다. 실행 세션 종료 시 수집도 종료된다. 신규 팝업 초기 요청 및 HTML/form payload 세부 구조는 아직 불완전하다. 전체 재귀 탐색, 글 작성·삭제·설정 변경과 다른 관리 API는 미검증이다.

전환 상태: captured=일부, client_exists=통계 조회, remnant_free=통계 클라이언트, credential_propagated=현재 별도 프로세스 확인, live_replay=통계 1개 확인.


## 재귀 탐색 진행 상태

관리 화면 43개 경로를 추가 탐색했다. 방문·유입·인구통계·동영상·게시물 순위 및 기본 설정 하위 화면을 포함한다. 총 네트워크 이벤트 293건에서 JSON 응답/쓰기 계약 23개를 정리했다. `recursive-map.json`에 inspected 43개, pending 99개가 저장돼 있다. pending에는 관리자 메뉴와 iframe 내부의 중복 경로가 포함되므로 99개의 별도 기능을 의미하지 않는다. `api-catalog.json`은 실제 관측한 응답 스키마이며, 독립 HTTP 재현은 기존 통계 1개 이외 추가 검증하지 못했다.

탐색 중 JavaScript 도구 시간 초과로 세션이 초기화됐다. 설치된 Chrome DevTools MCP 실행 파일로 복구했으나 Chrome 연결 응답이 대기 중이다. 이벤트 수집도 초기화 시점에 중단됐으며 재연결 후 다시 시작해야 한다. 전체 재귀 탐색 완료로 간주하지 않는다. 연결 복구 시 저장된 pending 노드부터 재개하고 완료된 노드는 재방문하지 않는다.
