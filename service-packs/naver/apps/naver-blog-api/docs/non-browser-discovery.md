# 브라우저 없이 이어가는 HTTP 탐색

로그인·세션 전달과 탐색을 분리합니다. 읽기 API는 `scripts/cli.mjs`, HTML·iframe·JavaScript의 관측 링크를 따라가는 탐색은 `tools/discovery/http-session.mjs`가 담당합니다. 이 탐색기는 페이지를 렌더링하거나 JavaScript를 실행하지 않습니다.

현재 55개 통계 GET 계약을 관측·구현했고, 그중 22개는 별도 Node CLI 프로세스로 현재 로그인 세션을 전달해 HTTP 상태 200·application status 200·통계 응답 구조를 확인했습니다. 새 33개 구현은 라이브 재현 전까지 별도로 구분합니다. `evidence/live-replays-2026-09-13.json`이 실제 검증 범위입니다.

## 인증 경계

일반 실행은 런타임 `NAVER_COOKIE`만 받습니다. `bootstrap`은 쿠키가 없으면 실패하며 브라우저를 자동으로 열거나 연결하지 않습니다.

`bootstrapChrome`은 사용자가 명시적으로 허용한 기존 Chrome의 네이버 로그인 세션을 한 번 읽는 선택적인 전달 도구입니다. 현재 확인된 9222 디버깅 서버와 이번 작업에서 확인된 네이버 통계 탭에 한정됩니다. UI 조작이나 다른 URL 이동은 하지 않습니다. 쿠키를 메모리의 HTTP 쿠키 저장소에 넣은 후 디버깅 연결을 닫습니다. 실행 프로세스가 종료되면 이 저장소도 사라집니다. 영구 로그인·자동 갱신·Windows 서비스는 아닙니다.

Chrome 연결 승인 대기·시간 초과와 네이버 인증 실패를 구분해야 합니다. 전달이 성공하기 전에는 HTTP 전용 탐색기의 로그인 상태를 준비 완료로 보고하지 않습니다. 브라우저 기반 조회 검증에 성공한 사실만으로 새 프로세스가 세션을 보유한다고 가정하지 않습니다.

## 실행 프로토콜

Node.js 24와 Python 3의 표준 라이브러리를 사용합니다. 별도 npm·pip 의존성은 없습니다. Python 실행 경로는 필요할 때 `PYTHON` 환경변수로 지정할 수 있습니다. HTML 파서 프로세스에는 인증 쿠키를 전달하지 않습니다.

```powershell
node tools/discovery/http-session.mjs
```

한 줄에 JSON 명령 하나를 stdin으로 전달합니다. 표준 출력은 비밀값 없는 결과 메타데이터입니다.

```json
{"id":1,"method":"bootstrap"}
{"id":2,"method":"root"}
{"id":3,"method":"scan","args":{"limit":10}}
{"id":4,"method":"source","args":{"limit":5}}
{"id":5,"method":"status"}
{"id":6,"method":"stop"}
```

인증 세션이 환경변수에 공급된 상태에서 사용합니다. 명시적으로 허용된 Chrome 전달을 이용할 때에만 첫 명령을 `bootstrapChrome`으로 바꿉니다. 쿠키·비밀번호를 이 JSON, 파일, 출력이나 Git에 기록하지 않습니다.

`root`는 기존 4053103 관리자 루트의 보호된 HTML을 실제 HTTP로 조회해 인증 경계를 확인합니다. `scan`은 저장된 pending 경로를 BFS로 처리하고 응답마다 체크포인트를 저장합니다. 신규 관측 링크의 동작 의미가 아직 불명확하면 candidate로 보존합니다. 로그인 안내 HTML, 401/403 또는 공통 인증 오류가 발생하면 대기열을 보존한 채 멈춥니다. 모든 query 선택자를 임의로 합치지 않습니다.

`source`는 해당 HTML에서 실제 관측한 JavaScript URL만 직접 가져옵니다. 소스에서 찾은 `/api/blog/` 문자열은 **후보**이며 XHR 캡처나 성공한 API 계약으로 간주하지 않습니다. HTML/form 응답도 JSON API와 구분합니다. 읽기 동작으로 확인되지 않은 저장·삭제·글쓰기·초기화 요청은 자동 실행하지 않습니다.

자동 HTML 요청은 이미 조회한 문서의 경로와 관측된 쿼리 필드 이름으로 제한합니다. 새 경로나 동작 선택자가 나오면 검토할 후보로 보존합니다. 계정 경로 아래에 있다는 이유만으로 읽기 동작이라고 가정하지 않습니다. 기존 HTTP 증거와 소스 대기열은 프로세스를 다시 시작해도 이어서 읽습니다.

## 현재 제한

HTTP 탐색기 소스는 구문 검사와 오프라인 테스트 대상으로 정리했습니다. 이 도구의 라이브 탐색 완료 여부는 별도 HTTP 탐색 영수증으로 판단해야 합니다. 최초 세션을 요청한 이전 수집 실행기와 이 HTTP 전용 실행기는 별개 프로세스입니다. 이번 전달 요청은 Chrome 연결 승인 시간 초과로 종료됐고 실행기도 중지했습니다. 따라서 이 HTTP 탐색기의 라이브 동작은 아직 검증하지 못했습니다.

현재 승인된 블로그와 관측 경로에 맞춘 탐색 도구이며 범용 로그인 SDK가 아닙니다. 일부 동적 메뉴는 HTML/JavaScript 소스만으로 확정할 수 없으므로 후보·미해결 상태를 남깁니다. URL 메뉴 대기열 소진을 모든 날짜·필터·쓰기 기능 검증과 동일시하지 않습니다.
